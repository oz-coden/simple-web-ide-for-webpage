# Simple Web IDE For Webpage

ブラウザ上で動作する、簡潔に使えるウェブページを作るための開発環境です。
書かれたコードの内容はすべてクライアント側に保存され、また、外部サーバーとの情報のやりとりなども必要ありません。

## 🎯 プロジェクトの背景と開発目的

基本的には、誰でも環境の設定等を必要とせずに使うことのできる、簡単なウェブページを作るための体験ができるサイトとしての機能を持った開発環境の作成を目的として作っています。
また、これ自身も私が以前から作ってみたいと考えたもので、学習を主軸において作成されています。なお、必要であれば、このエディタ自身を使ってこのエディタのコードを記述したり、追加することも可能です。

これは次のことを念頭に置いて作っています。

1. 誰でも使用できる
   ブラウザ上で動作しており、また、特段の環境構築やサーバーとの通信、ソフトウェアのダウンロードなどを必要とせず、これ単体で使用できます。
2. ホットリロード
   コードを変更すると、即座にプレビューされるようにすることで、追加した要素がどこにどのように反映されているかを実際に体験することができるようにしています。学習者が、特定のマークアップやコードについて、どのように動作するかをすぐに確かめられます。また、ブラウザ上で動作できるようにすることで、ホットリロードの機能の大半をブラウザに任せることで、他のアプリケーションを開くことなくプレビューできます。
3. 内容が保存される・保存できる
   Local Storageを使用することで、途中まで編集した内容を自動で保存し、ブラウザが終了しても次立ち上げたときには途中から再開して編集することができます。また、ダウンロードを行うこともでき、実際に編集したコードをローカルに保存することができます。

## 機能
- Visual Studio Codeをベースとしたシンタックスハイライトを搭載したMonaco Editorを使用しています。
- ホットリロードに対応しており、コードを変更すると、その内容をもとにプレビュー画面へ変更を適用します。
- HTML以外に、CSS、JavaScriptに対応した3つの最小限のファイルを編集できます。最小限の編集や、学習用途としてこの3つをサポートしていることで、フロントエンドのウェブページ編集の学習を行うことができます。また、簡単なウェブページの作成も可能です。
- LocalStorage機能を使用しており、入力のたびに自動バックアップを行います。ブラウザを閉じても、次回起動時に前回の状態から安全に再開できます。
- 編集した各ファイルは、対応したボタンをクリックすることで、ワンクリックでローカルへダウンロードすることができます。
